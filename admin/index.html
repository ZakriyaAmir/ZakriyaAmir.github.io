GitHub token (for video, image and resume uploads)

Uploads are committed to the private repo ZakriyaAmir/Zakriya-Portfolio (videos under assets/videos/, the resume as assets/Zakriya-Amir-Resume.pdf), which triggers the normal deploy — a file goes live after the deploy finishes (~2 min). Create a fine-grained personal access token at github.com → Settings → Developer settings, with access to only the Zakriya-Portfolio repo and permission Contents: Read and write. It is stored only in this browser (localStorage) — never in Supabase, never sent anywhere except api.github.com.
